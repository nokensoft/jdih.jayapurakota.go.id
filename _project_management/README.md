# Manajemen Proyek — Pemeliharaan Website JDIH Kota Jayapura

Dokumen administrasi proyek Nokensoft. Folder diberi nomor sesuai urutan alur kerja.

| Folder | Isi |
|---|---|
| `00-template/` | Aset dokumen resmi Nokensoft (kop surat v.2) |
| `01-anggaran/` | Pagu anggaran Rp 25.000.000 dan perhitungan pajak dari dinas |
| `02-penawaran/` | RAB Penawaran (DRAFT v.1.0) dalam format .docx dan .pdf |
| `03-presentasi/` | Presentasi fitur utama website (HTML siap export ke PPTX) dan tangkapan layarnya |

## Konvensi

- File baru masuk ke folder sesuai tahapnya. Tahap baru diberi nomor berikutnya (mis. `04-serah-terima/`).
- Revisi dokumen diberi penanda versi di nama file: `... DRAFT v.1.0`, `... v.1.1`, `... FINAL`.
- Perhitungan pajak (`01-anggaran/`) berasal dari dinas dan **tidak boleh diubah**.
