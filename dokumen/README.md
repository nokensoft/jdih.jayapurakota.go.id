# Berkas Dokumen Hukum — Prototype JDIH Kota Jayapura

Salinan PDF dokumen hukum **asli** Pemerintah Kota Jayapura, diunduh dari
[JDIH BPK RI](https://peraturan.bpk.go.id/Search?entitas=214) pada 26 November 2026
untuk keperluan simulasi tampilan. Metadatanya ada di `assets/js/data-dokumen.js`.

Struktur: `dokumen/<jenis>/<tahun>/<jenis>-<nomor>-<tahun>.pdf`

Belum ada folder untuk **Keputusan Walikota, Surat Edaran, dan Monografi Hukum** karena
dokumen jenis ini tidak ditemukan di sumber publik. Di situs, jenis tersebut masih memakai
data contoh (`contoh: true`, tanpa berkas) dan perlu diganti dengan dokumen asli dari Bagian Hukum.
